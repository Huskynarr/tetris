# Contributing to Math-IT Projects

Thank you for your interest in contributing to scientific visualizations at Albert-Ludwigs-Universität Freiburg!

## Guidelines

1. **Modular Design**: Keep code self-contained within the project directory.
2. **Code Style**: Use semantic markup for HTML, clean styling in CSS, and comments in JavaScript/Python.
3. **Kiosk Optimization**: Ensure all interface elements are large enough for touchscreen interactions.
4. **Mathematical Depth**: Any game addition or feature must be accompanied by an update in the Mathematics tab explaining the scientific context.
